# caiqueDeOliveira-dev.github.io

Site raiz da conta GitHub Pages — `https://caiquedeoliveira-dev.github.io`.

Hoje este repositório existe para **verificação de domínio do TikTok Developers**:
os arquivos `tiktok-developers-site-verification=*.txt` precisam ficar acessíveis
na raiz do domínio para o TikTok validar a posse do site no cadastro de aplicativos.

## Estrutura

| Arquivo | Função |
|---|---|
| `tiktok-developers-site-verification=*.txt` | tokens de verificação do TikTok |
| `tiktokVKkc85BZ2jj0Ec25xqfGy7b55TtGjM5w.txt` | verificação auxiliar |

## Regras

- **Não** remover nem editar os `.txt` de verificação — o app quebra no TikTok.
- GitHub Pages publica a raiz do branch `main` diretamente, sem build.
